## Architectural decisions locked in

1. **Cyprus VAT 19%** — server-side only, via `allocate_invoice_number(workspace_id, year)` SP wrapped in `pg_advisory_xact_lock`. Drafts use UUID; finalize swaps to real number atomically.
2. **Trust ledger** — separate Postgres table, append-only via `deny_trust_mutation()` trigger + TRUNCATE guard (Migration 005). NEVER appears in revenue views.
3. **PDF rendering** — `@react-pdf/renderer` only, no Puppeteer. `Font.register` at module top-level in `src/lib/pdf/adapter.ts`. Noto Sans Variable + Crimson Pro Variable in `public/fonts/`. Hyphenation disabled.
4. **Service-role bridge** — ONE place: `(workspace)/invoices/actions.ts → finalizeInvoiceAction`. Verifies workspace ownership via regular client first, then switches to `createServiceClient()` only to call `allocate_invoice_number`. RLS deny-by-omission: every UPDATE/DELETE Server Action checks `data.length === 0`.
5. **i18n** — `next-intl` 4.x, cookie-driven, `el-CY` default. Catalogues at `messages/{el-CY,en-CY}.json`, KEY PARITY mandatory. `lib/format.ts` is the single Intl seam.
6. **DESIGN.md tokens** — OKLCH in `globals.css`; UI consumers use `var(--token)` or `color-mix(in oklch, var(--token) X%, transparent)`. PDF templates are the ONE legitimate exception (StyleSheet subset = hex equivalents in `LexPdfTokens`).
